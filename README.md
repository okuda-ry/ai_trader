# プロジェクト名: AI Trader

概要

- 本プロジェクトは、LLM を用いた自動トレーディングの実験的プロトタイプです。市場データの特徴量抽出、トレード戦略の決定、注文実行、メモリ／ログ管理を含みます。

主要コンポーネント

- `bot/market.py`: 市場データ取得・前処理
- `bot/features.py`: 特徴量生成
- `bot/strategy.py`: トレード戦略（シグナル生成）
- `bot/trader.py`: 注文作成と実行ロジック
- `bot/execution.py`: 注文実行の抽象化・ラッパー
- `bot/memory.py`: 状態・履歴の保存（短期メモリ）
- `bot/llm_agent.py`: LLM を使った意思決定エージェント
- `bot/runner.py`: 実行エントリーポイント（シミュレーション／デプロイ用）
- `bot/runner.py` を使ってローカルで実行できます。

セットアップ

1. Python 3.8+ を用意
2. 依存関係をインストール:

```
pip install -r requirements.txt
```

実行例

```
python bot/runner.py
```

`data/` に市場データ、`logs/` に実行ログが出力されます。

注意事項

- 本コードは研究用プロトタイプであり、実運用のガイドや投資助言を提供するものではありません。
- 本番運用前にリスク管理や例外処理、接続先（取引所）固有の認証・制約を必ず実装してください。
